# Engineering Portfolio

Personal engineering portfolio showcasing my work in mechanical engineering, bioengineering, and software development.

The website includes selected engineering projects, technical documentation, and information about my academic and professional experience.

## Built With

- HTML
- CSS
- JavaScript
- Vite

The website is built using vanilla JavaScript and custom CSS, without a frontend framework or UI component library.

## Project Structure

- `src/main.js` — Page rendering and navigation
- `src/projects.js` — Project information and display order
- `src/style.css` — Layout, styling, and responsive design
- `public/` — Static assets and project images

## Development

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Build the website:

```bash
npm run build
```

## Deployment

The website is hosted on GitHub Pages and deployed using GitHub Actions.
