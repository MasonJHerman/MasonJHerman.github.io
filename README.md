# Mason J. Herman — Engineering Portfolio

Personal engineering portfolio built with Vite, HTML, CSS, and JavaScript.

## Local preview

From this directory, run:

```bash
npm install
npm run dev
```

On Windows PowerShell, use `npm.cmd` in place of `npm` if script execution is restricted.

## Production build

```bash
npm run build
```

The build output is written to `dist/`.

## Files

- `src/main.js` — page content and navigation
- `src/projects.js` — project case studies
- `src/style.css` — site styling
- `public/images/headshot.jpg` — portrait used on Home and About
- `public/resume.pdf` — downloadable resume
